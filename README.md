# White Box

**自分との約束を、現実の行動と成果までつなぐ実行基盤。**
Windows のデスクトップアプリ（Electron + React + TypeScript）。記録はこの PC の中だけに残る。

解こうとしているのは、タスク管理でも Pomodoro でもなく、次の一点：

> 自分が何を目指し、何を重要だと決め、実際に何をして、何にどれだけ時間を使い、どこまで進んだのかが、あとから分からなくなる。

名前は航空機のブラックボックスの反転。あの装置は「中が読めない箱」ではなく、**何が起きたかを必ず残して、あとから読めるようにする装置**（実物は見つけやすいようオレンジに塗られている）。名前だけが誤解を招いていたので、名前の側を正した。

---

## 動かす

```bash
npm install
npm start
```

デスクトップとタスクバーに置くところまでは [docs/packaging.md](docs/packaging.md)。

## 一日の流れ

```
PC を使い始める
  → Welcome（やると決めていること・止まっている重要タスク・今日どうするかの余白）
  → Ctrl + Alt + S でタスクを選んで開始
  → 作業（一時停止・再開・タスク切替）
  → 50 分で満了ポップアップ（終了 / +15分続ける / 5分休憩 / 次のタスクへ）
  → 終了レビューで「どこまで進んだか」だけ確認
  → 今日タブで、実際に何にどれだけ使ったかを見る
```

## ショートカット

設定でいつでも変えられる。

| キー | 動き |
| --- | --- |
| `Ctrl + Alt + S` | 何も動いていなければ開始画面。実行中なら一時停止。停止中なら**確認なしで即再開** |
| `Ctrl + Alt + W` | 現在の仕事（今のタスク・ほかのタスク・分解・切替） |
| `Ctrl + Alt + D` | メイン画面 |
| `Ctrl + 1..6` | メイン画面のタブ切替（今日 / ボード / 記録 / 設定 / 道標 / 問題・改善） |

## 画面

| 画面 | できること |
| --- | --- |
| **今日** | 記録した総作業時間、一日の帯（何時に何をやったか）、セッション一覧。行を開くと記録の修正・削除 |
| **ボード** | Inbox / Todo / Doing / Done のかんばんと、締切・優先度を編集できる一覧。同じタスクを共有し、目標へ戻れる。ドラッグで移動、任意の入れ子、進捗、プロジェクト絞り込み |
| **記録** | 日ごとの合計と全セッション |
| **道標** | 目標マップ・構造の履歴と、目標に結びつく問題・タスク。旧道標のJSON取り込みにも対応（[操作と移行](docs/michishirube.md)） |
| **問題・改善** | 全体と目標別の問題／問い／改善を一覧。解決・編集と、該当する目標への移動 |
| **設定** | 名前、ショートカット、既定のセッション長、自動一時停止、一日の境目、停滞の日数、プロジェクト、書き出し／読み込み |
| **開始**（最前面） | タスクを探して選ぶ／その場で作って開始。キーボードだけで完結 |
| **HUD**（最前面・小） | 残り時間の輪、今のタスク、一時停止・終了。× で閉じても計測は続く |
| **満了**（最前面） | 終了 / +N分続ける / 時間を選んで休憩 / 次のタスクへ。休憩後は再開を押すまで停止 |
| **レビュー** | 実作業・停止・タスクごとの時間、進捗の更新、そのセッション中に生まれたタスクの整理 |
| **現在の仕事**（最前面） | 分解、ほかのタスクへの切替、思いついた仕事の追加 |

## 記録の考え方

- **実作業時間 = 経過時間 − 一時停止の重なり。** スリープと画面ロックでも自動的に止まる
- **同じ瞬間に前面のタスクは1つ。** セッション中に切り替えると区間として時刻ごと残る
- **1 セッション = 1 タスクでも、途中で切り替えてもよい。** どちらも強制しない
- **進捗（0〜100%）は人間が宣言する値。** 子タスクや実績時間から自動計算しない
- アプリが落ちても、最後に記録が取れた時刻でセッションを閉じられる。PC が止まっていた時間は実作業に入らない

## データ

`%APPDATA%\white-box\data\data.json`（設定 → データ →「保存先を開く」）。
保存は一時ファイル経由の置き換えで、途中で落ちても本体は壊れない。`backups/` に日ごとのコピーを 30 日ぶん。書き出し／読み込みで PC を移せる。

外へは何も出ない。ネットワークへ出る処理も、外部フォントの読み込みも無い。

## 開発

```bash
npm test          # 時間計算・タイマー表示・道標の単体テスト
npm run typecheck # レンダラとメインプロセスの型検査
npm run icons     # アイコンを作り直す
npm run pack      # 配布物を組み立てる

node scripts/e2e.mjs              # 実アプリを起動して IPC 経由で通し確認
node scripts/e2e-goals.mjs        # 道標のUI・取り込み・保存と再起動を確認
node scripts/seed-demo.mjs .demo  # 動作確認用データを書き出す
```

検証の考え方と落とし穴は [docs/verification.md](docs/verification.md)、構成は [docs/architecture.md](docs/architecture.md)。
