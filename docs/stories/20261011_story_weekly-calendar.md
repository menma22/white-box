# 週間の予定と記録を、一枚のカレンダーで扱う

## 目的

2026-10-11のまひろの依頼: 7日を一画面で見渡し、予定の作成、実際に使った時間、定型時間、プロジェクトごとの週予算を同じ場所で確認・調整する。添付のGoogleカレンダー週表示は見た目と操作の参考。既存の週間実績と時間配分の縦長な表示を統合する。

## 受け入れ条件

- [x] 14:58の直接指示: 初期表示は薄い操作ヘッダーと大きな7日カレンダーで作業領域を満たす。時間配分・集計・他情報は下にスクロールして見られる。時刻文字を毎時間密集させない。評価の高いカレンダーの一次情報と実UIを参考にする。
- [x] 7日×時刻の週カレンダーに、予定・外部固定予定・定型時間・実作業を表示する。予定と実績を線・面・文言で区別し、重なりでも操作できる。
- [x] 週移動・今週へ戻る・日付指定・予定/実績の表示切替・24時間全体と拡大表示を提供する。 日付の入力途中や未対応年で表示を壊さず、現在の7日表示を保持して正常値へ戻せる。
- [x] 空き時間のクリックまたはドラッグ、日付の追加ボタンから予定を作成できる。タスクを持たない予定・プロジェクトのみの予定も保存できる。
- [x] 睡眠・食事・その他の固定時間を、曜日と時刻を指定した毎週の定型予定として登録・変更・取消できる。繰返しの開始日と終了日、夜跨ぎを扱う。編集/取消は予定全体へ適用することを明記する。
- [x] 予定の登録は実績を増やさず、自動でセッションを開始しない。既存の外部固定予定とセッションを保持し、実績は既存activitySlicesの一時停止・除外・重複の処理を通す。
- [x] 週間の時間予算とプロジェクト別の予定・実績を並べる。既存の下限・上限・範囲・上限なしと既定配分の再利用を維持する。
- [x] 定型生活時間は予算で最低確保する。生活予定と外部固定予定が重なる時刻を二重控除しない。手入力の生活時間は週の総量で、予定として配置済みの同カテゴリ時間に足さない。
- [x] 既存予算は外部固定作業を除いた柔軟な時間の配分。総実績と、外部固定予定の時間帯を除く配分対象実績を明確に区別する。
- [x] 週カレンダーと全週指標は暦の月曜0:00〜翌月曜0:00で統一する。「今日」の設定された一日の境界は変更しない。
- [x] 過去/未来/空の週、長いタイトル、短い記録、重なる予定、24時を跨ぐ記録、削除済みのタスク/プロジェクトを表示できる。 既存の週全体と各日のプロジェクト/タスク別内訳を詳細表示に保持する。
- [x] 保存失敗時に入力を残す。保存中と未保存入力があるダイアログでは閉じる/移動/終了で黙って入力を失わない。
- [x] optional永続データとstrict IPCで旧DBの読み込み・export/import・保存失敗rollbackを維持する。
- [x] 型・lint・全テスト・build・既存E2Eと週間UIの実操作、1440/900px・短い高さ・拡大表示を確認し、画像・保存の読み返し・再起動・レンダラエラーの証拠を残す。

## 範囲

週間画面を中心に変更する。外部カレンダー同期、予定からの自動開始、目標の自動達成判定、週次レビュー、全画面のデザイン変更は含めない。予定取消は履歴を保持する。

## 設計メモ

- core は現地の週境界・定型予定の展開・区間の重なりと時間予算を計算する。実績は既存の activitySlices / engine を使う。
- contracts の strict IPC と optional calendarBlocks を入口に、desktop が既存 commitChanges と保存失敗時の rollback を通して予定を永続化する。セッションの処理は継続してメインプロセスが持つ。
- renderer は週間カレンダー・予定編集・予算と記録の表示を担当する。表示切替は既存 Segmented、編集の保存・閉じるは既存の bridge / draft participant / Modal を使う。
- 週の表示と集計を月曜0時へそろえる。Today / History の設定された日境界、既存の記録、予算の4方式、外部固定予定の契約を保持する。

## 検証の範囲と終了待ちの制限

planningの通常実行はソース・配布版とも最初の自然終了の15秒待ちで失敗した。終了前の機能条件は成功し、その後の後処理では自然終了code 0・所有PIDなしを記録した。同じ配布版の元の隔離data/profileで保存内容と元の8再起動条件を別に確認した。復元検証は通常planning全工程の成功へ置き換えない。一般の間欠終了問題の根因・解消は未確認で、15秒以内の終了を保証しない。受け入れ条件の原文は変更していない。
