# タイマー満了で実作業の計上を止める

## 目的

予定時間に達してから満了画面を操作するまでの放置時間を、実作業へ加算しない。[仕様書](../product-spec.md)の実行記録・Timer満了Popup（Phase 1、1-12）を守る。

## 受け入れ基準

- [x] 一時停止を差し引いた正確な予定到達時刻に停止を保存する。
- [x] 通知の刻みが遅れても実作業・タスク別実績は予定時間で止まる。
- [x] 明示延長した時点から実作業を再開し、放置時間は残る。
- [x] 満了後の再開ショートカットは確認窓を示して停止を保つ。満了後の休憩終了画面からは延長か終了を選べる。
- [x] 通知前の終了と異常終了からの復旧終了でも満了後を計上しない。
- [x] 満了画面で、続けるまで実作業時間が増えないことを示す。
- [x] 終了済みの旧記録と事後の除外編集は従来どおり扱う。

## やらないこと

セッション方式・整理時間の除外・タスク未割当開始の追加。

## 設計メモ

coreの計算上限とdesktopの状態遷移に同じ予定到達時刻を使う。contractsの停止理由に`expired`を追加し、操作・毎秒tick・復旧終了から満了を確定する。rendererは満了状態の説明を表示する。コマンド数は44のまま。

## 検証

- `pnpm run typecheck` / `lint` / `test` / `build` 成功。全126テスト、44コマンドの契約検証を含む。
- `node scripts/e2e.mjs` 成功。
- `node scripts/e2e-session-modes.mjs` の満了・再開拒否・休憩後延長・描画例外の8項目成功。
- `pnpm run pack` 後、`WHITEBOX_EXE`を配布EXEへ指定した両E2Eも成功。
- 満了画面と満了後の休憩終了画面の実描画PNGを確認。
- 再開拒否のdomain・受け口テスト3件は修正前に失敗し、修正後に成功した。
