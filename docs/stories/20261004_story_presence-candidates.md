# 離席候補を本人の確認後に記録へ反映する

## 目的

顔が見えなかった区間を、本人が確認するまで実作業から引かない。保存された離席候補をレビューに表示し、離席だった場合だけ除外として反映する。カメラによる候補生成は次のPRで接続する。

## 受け入れ条件

- [x] 未確認の候補を保存・再読込しても、作業時間は変わらない。
- [x] 終了したセッションで本人が確認すると、候補内の実作業だけを除外する。
- [x] 既存の一時停止・休憩・除外と重なる時間を二重に引かない。
- [x] 見送りと再確認では、作業記録を変更しない。
- [x] 実行中のセッションへの除外反映を拒否する。
- [x] 不正な日時・状態・重複IDを拒否する。
- [x] 実画面で候補と確認結果が読め、型検査・lint・テスト・build・E2Eが成功する。

## 対象外

カメラの起動・顔の推論・自動除外。

## 設計

`presenceCandidates` はセッションと別に保存する。`presence:resolve` の本人確認で、セッション内の停止区間を除いた候補の範囲だけに `excluded` を追加する。元の停止区間を保持し、再確認は冪等にする。レビューと記録画面に表示し、再起動後も確認へ戻れるようにする。候補の生成・観測コマンドはこのPRでは公開しない。

## 検証

型検査・lint・単体テスト126件・build・packが成功。ソース版と配布版で既存E2E32項目と候補E2E13項目が成功し、renderer例外は0件。未確認の保存、実行中の反映拒否、実画面の確認・見送り、停止済み区間の保持、4つの実作業区間だけの除外、再確認の冪等性、終了とPID消滅、再起動後の記録画面を確認した。候補と確認済み表示のPNGを目視確認した。
