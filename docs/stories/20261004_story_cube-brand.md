# White Box の立方体ロゴ

## 目的

White Box の名前を、細い輪郭と中心から伸びる3本の線で構成した立方体で表す。アプリ内のマーク、Windowsアイコン、トレイアイコンに同じ形を使う。

## 受け入れ条件

- [x] 立方体の外周と3本の稜線があり、右側の1面だけがキャラメル色になる。
- [x] ヘッダーのSVGとPNG・ICOに同じ座標・線幅を使う。
- [x] 16px・32px・256pxで輪郭が読め、画像の端で欠けない。
- [x] アイコンを再生成すると同じアセットになる。
- [x] 型検査・lint・テスト・build・E2Eを通し、パッケージ版でも起動する。

## 対象外

画面全体の形・色・レイアウトの変更、他社ロゴの流用。

## 設計

24×24の座標で外周を `(12,2.5)`、`(20.5,7.3)`、`(20.5,16.7)`、`(12,21.5)`、`(3.5,16.7)`、`(3.5,7.3)` に置く。中心は `(12,12)`、線幅は1.25。既存の色トークンを使い、生成スクリプトも同じ図形を描く。

## 検証

`pnpm run typecheck`・`pnpm run lint`・`pnpm run test`（118件）・`pnpm run build`・`pnpm run pack` が成功。`node scripts/e2e.mjs` はソース版と `WHITEBOX_EXE` を指定した配布版で全32項目が成功。配布版の `node scripts/e2e-timeline.mjs` も成功し、実画面のヘッダーロゴと16px・32px・256pxの画像を目視確認した。生成した7アセットが元の完成品と一致することを確認。コメント専任レビューはPASS。
