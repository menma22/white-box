# AIから本人が依頼したタスクを登録する

## 目的

[製品仕様の External / AI Integration](../product-spec.md#phase-7--external--ai-integration) を起点に、MCP対応エージェントが本人の目標・タスクを参照し、依頼された作業を親子構造のInboxタスクへ登録できるようにする。

## 受け入れ基準

- [x] AI連携は既定で無効。設定画面から有効化し、MCP接続設定をコピーできる。
- [x] ローカルHTTPは127.0.0.1だけで待受け、トークン認証・Host・Origin・形式・サイズ・許可コマンドを検査する。
- [x] MCPでプロジェクト・目標・タスク・直近100件のセッションを参照できる。
- [x] 親子・プロジェクト・目標・期限・優先度・メモを含むタスク案をInboxへ一括登録できる。
- [x] 同じrequestIdの再送は同じIDを返す。異なる内容の再送・不正な案は一部だけ保存しない。
- [x] 保存・アプリとMCPの再起動後も登録内容と再送の重複防止が維持される。
- [x] 配布EXEでもコピーされたMCP設定が実際に動く。

## やらないこと

実績の割当・完了提案と本人確認、入力監視、開始通知、ノート、カメラによる不在検知はこの変更に含めない。

## 設計メモ

contractsの3コマンド、coreの登録依頼型、desktopの登録・参照ハンドラと認証付きHTTP、設定UI、stdio MCPと配布物への同梱を変更する。登録は全件を一時データで検査してから保存する。背景サービスはAI APIの有効・無効と終了だけを扱う。

## 検証

2026-10-04、型検査・lint・135件の単体テスト・ビルド・基本E2E・道標E2E・packが通過した。登録ハンドラ10件と実HTTP7件で、一括登録・不正案による全体の不変・再送・認証・許可コマンド・strict引数を確認した。

`node scripts/e2e-agents.mjs` は最新ソースビルドと配布EXEの両方で21項目が通過した。実際の設定UIで有効化し、コピーしたJSONからMCPを起動して、目標の参照、期限付き親子登録、再送、変更された再送の拒否、不正期限による全件失敗、保存、アプリとMCPの再起動後の再送まで確認した。既存タスク・実行記録・日誌は保持された。設定UIのPNGを実物確認し、rendererのconsole error・未処理例外は0件だった。配布EXEの基本E2Eも通過した。
