# 道標の枝の付け替えと中継目標 — v1

2026-10-17。まひろの依頼を受けた実装前の受け入れ基準。

## 目的

固定された親子関係を、その場で組み替えられるようにする。product-spec.md §25 の「無駄な摩擦は消す」「Goal は大切なものとして扱う」に従う。

## 受け入れ基準

- 枝の「切り取る」から、付け先のカードを選んで子孫ごと付け替えられる。
- 別の最上位目標へ移動でき、一覧から付け先を選ぶキーボード操作もできる。
- キャンセルと Escape では元の構造を保持する。保存中の重複操作を防ぐ。
- 自分・子孫・現在の親・隠した枝を付け先にできず、IPC でも不正操作を拒否する。
- 子を最上位へ切り離せる。元の目標ID・子孫・関連タスク・問題・成果・成功条件を保持する。
- 接続の「間に目標を追加」から親 → 新しい目標 → 元の子にできる。兄弟順と元の子の配下を保持する。
- 付け替え・挿入は1回の保存で反映し、失敗時は元データを保持する。構造の履歴・保存読戻し・再起動でも関係を保持する。
- 実アプリのUI・PNG・エラー監視、型・lint・単体テスト・ビルド・既存E2Eと配布exeで確認する。

## やらないこと

目標の削除、自由座標への配置、兄弟の並べ替え、複数枝の一括移動、既存データの移行。

## 設計メモ

contracts の strict IPC に goal:reparent / goal:insert を追加し、desktop の既存の複製・検証・保存経路を使う。renderer は付け替え待ち状態だけを持ち、確定まで木を変更しない。自動レイアウトは既存のまま使う。既存の目標・問題・タスクの参照IDを変えない。
