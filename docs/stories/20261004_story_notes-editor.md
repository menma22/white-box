# ノートを編集して保存する

## 目的

作業中に浮かんだ考えをタスクや日誌とは別に残し、検索して続きへ戻れるようにする。[製品仕様](../product-spec.md)の実行と記録を補助する。

## 受け入れ基準

- [x] ノート画面でタイトル・本文を編集し、自動保存とCtrl+Sで保存できる。
- [x] 保存中の追加入力と状態配布で下書きを失わず、保存失敗時に入力を保持して再送できる。
- [x] 新規作成・選択切り替え・別タブへの移動の前に下書きを保存し、失敗したら編集欄を保持する。連続した作成操作で重複しない。
- [x] プロジェクト・タスクを関連付け、ピン留め・全語検索・絞り込みを利用できる。
- [x] アーカイブと復元で本文・関連先を保持する。
- [x] 保存後の再起動でノートを復元し、ノートがない旧DBと既存のタスク・日誌を保持する。
- [x] 最小940×620画面で一覧と編集欄を操作でき、横方向にはみ出さない。

## やらないこと

予定日時・OS通知・今日の画面へのリマインド表示は後続のstoryで実装する。

## 設計メモ

coreでノート型と検索、contractsでstrictな3コマンド、desktopで操作・保存・状態配布、rendererで一覧と自動保存の編集欄を追加する。保存は変更した項目だけを順番に送信し、失敗時は下書きを保持する。

## 検証

- `pnpm run typecheck`・`pnpm run lint`・`pnpm run test`・`pnpm run build` を通過。単体テスト135件が成功。
- `node scripts/e2e.mjs` と `node scripts/e2e-notes.mjs` を通過。ノートE2Eは16項目が成功し、rendererエラーは0件。
- 実Electronで新規作成・二重作成抑止・入力・状態配布中の下書き保持・検索・関連付け・ピン留め・アーカイブ復元・再起動を確認。
- 通常編集と940×620のPNGを目視確認。小さい画面で一覧256.9px、編集面455.4px、本文230px、編集幅413.3px、横方向のはみ出し0px。
- 保存中の入力保護条件を一時的に除くと巻き戻り検出テストが失敗し、復元後は自動保存6件とハンドラ13件が成功。
- 撮影前に検証ウィンドウを前面へ戻す。終了は子プロセスのexit状態またはPIDの消滅で確認し、成功した最終E2Eは両起動とも強制終了なしで終了した。
- ブランチ切り替え前の派生成果物を別領域へ退避して `pnpm run pack` を成功させ、ノート編集だけを含む配布物を再生成した。後続の予定通知・入力監視・AI・カメラ検知のモジュールが配布物にないことを確認。
- 共通のUI排他runner経由で配布版の基本E2E32件とノートE2E16件が成功。配布先の実ファイルへ接続し、保存・検索・関連付け・アーカイブ復元・再起動・940×620表示を確認し、rendererエラーは0件だった。
- 配布版の通常編集と940×620のPNGを目視確認。両起動は強制終了なしでPIDの消滅を確認し、検証用Electronの残存は0件だった。
