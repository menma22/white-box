# ミニカードをコンパクトに固定表示する — v2

版: 2（2026-10-19）。[前版v1](20261019_story_compact-hud-v1.md)を保持し、退避を判定する領域・停止表示・対象外の操作の説明を明確にする。要件の変更はない。

## 目的

[プロダクト仕様 §3・原則2](../product-spec.md#3-全体設計原則)の操作上の摩擦を減らす考え方に沿い、作業を遮る大きなミニカードと画面の隅を行き来する退避を、小さい定位置表示へ変える。

直接の根拠はユーザーの「日付表示の上に小さく」「経過の数字だけでいい」「ゲージは残り時間」「時計回り」「もっとコンパクトに」「角ももっと丸く」「ゲージもちょっとだけ太く」「色やっぱオレンジ」という指定。

## 受け入れ基準

- 経過時間の数字だけを、丸みのある小さい長方形へ表示する。
- オレンジの外周ゲージが残り時間を表し、上中央から時計回りに空白が広がって減る。満了後は空になる。
- プライマリ画面の作業領域の右下へ配置し、下端のタスクバーの日付表示の上に置く。カーソルが別画面にあっても定位置を変えない。
- 定位置にある退避前の88×26のカード領域にカーソルがある間はカード1枚の高さだけ上へ退避し、領域から出たら戻る。移動途中の出入りにも追従する。
- クリックを背後のアプリへ素通りさせ、設定で非表示にできる。停止中は経過数字と残量を維持し、休憩中は休憩の経過と残りを示す。ストップウォッチでは経過を表示し、予定時間のないゲージは空にする。

## 対象外

タイマーの計測・保存形式、作業計測を開始・停止・再開・終了する操作、タスクバー設定の変更。タスクバーが画面下にある配置を対象とする。

## 設計メモ

desktopのwindows.tsが定位置とカーソル退避を管理する。rendererのHudWindow.tsxは既存のliveTimerPresentationから経過と残り時間を受け取る。残り時間の比率は0〜1へ収め、計測やデータの更新をrendererへ移さない。色はtokens.cssへ置く。

カード88×26、角半径9、外周線2.5 CSS px。透明ウィンドウ96×36へ影の余白を確保する。画面移動はsetBoundsで寸法も再指定し、移動による窓の拡大を防ぐ。休憩では既存仕様に合わせ休憩の経過と残りを使う。

検証の実測結果はPR本文とレビュー資料で示す。本版の要件本文は更新せず、要件を改訂する場合は次版を作る。
