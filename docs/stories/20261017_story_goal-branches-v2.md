# 道標の枝の付け替えと中継目標 — v2

2026-10-17。[v1](20261017_story_goal-branches-v1.md)の受け入れ範囲を保持し、非表示・履歴・保存経路の説明と検証結果を追加した。

## 目的と前提

道標は目標カードを親子の木で整理する画面。枝は1枚の目標と、その下にあるすべての子孫を指す。固定された親子関係を、カードの作り直しなしで組み替える。[製品の判断基準](../product-spec.md#25-最終的な設計思想機能追加で迷ったときの判断基準)の「無駄な摩擦は消す」「Goal は大切なものとして扱う」に従う。

既存の「枝を隠す」は対象と子孫を表示から外す機能で、データを削除しない。隠れた祖先の下の目標も、表示へ戻すまで移動・挿入の対象にしない。「構造の履歴」は目標の追加や親子関係の変更を記録して対象へ移動できる一覧であり、操作を巻き戻す機能ではない。

## 受け入れ基準

- [x] カードのハサミ、または詳細の「枝を切り取る」から、付け先のカードをクリックして子孫ごと移動できる。
- [x] 一覧から付け先を選べる。別の最上位目標への移動と、枝の最上位への切り離しができる。
- [x] 付け先の確定までは木を変えない。キャンセルと Escape で構造を保持し、保存中の重複操作を防ぐ。
- [x] 自分・子孫・現在の親・隠れた枝を画面で付け先にできない。バックエンドでも自分・子孫・隠れた枝への移動を拒否し、現在の親への移動は無変更とする。
- [x] 移動しても目標ID・子孫・関連タスク・問題・成果・成功条件と、残る兄弟の順序を保持する。
- [x] 接続上の「＋」、または詳細の「親との間に目標を追加」で、親 → 新しい目標 → 元の子にできる。元の子の配下と兄弟順を保持する。
- [x] 付け替えと挿入をそれぞれ1回で保存し、保存失敗では元データを保持する。変更を構造の履歴に記録し、保存・再起動・書き出し読込・旧道標の追加取込でも関係を保持する。
- [x] 最小940×620の画面でも付け替え操作・キャンセル・ズームを画面内に表示する。

## やらないこと

目標の削除、自由座標への配置、兄弟の並べ替え、複数枝の一括移動、Undo、既存データの移行。

## 設計メモ

`packages/contracts` は画面とメインプロセスの通信（IPC）のコマンド名・引数・戻り値を定義する。`goal:reparent` と `goal:insert` を追加し、余分な引数や型違いを拒否する既存の strict スキーマを使う。

`apps/desktop/src/domain/goal-ops.ts` が木を複製して検証・変更し、既存のハンドラと `commitChanges` が保存・失敗時の巻戻し・全画面への状態配信を行う。画面側は付け替え待ち状態だけを持ち、木の正本や保存処理を複製しない。自動レイアウトを再利用する。

## 検証

型検査・lint・単体72ファイル726テスト・本番ビルドに成功。ソース版と配布exeの既存基本E2E、道標E2E75条件、保存再起動と実画面PNGを確認した。循環拒否、保存故障からの巻戻し、成功条件・成果・関連レコードの保持を単体テストでも確認する。
