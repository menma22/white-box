# 現在の仕事を整理する時間を実作業から除く

## 目的

[仕様書](../product-spec.md)の「管理すること自体を仕事にしない」とPause UI（Phase 1、1-10）に沿い、現在の仕事の選択・整理中を実作業へ加算しない。

## 受け入れ基準

- [x] 現在の仕事の窓を開くと整理時間が始まり、その間の実作業は増えない。
- [x] 窓を閉じると、元が実行中のセッションだけを再開する。
- [x] 元の手動停止・整理中に指定した停止は閉じても保つ。
- [x] 重なる停止は二度差し引かない。
- [x] 整理中の異常終了・再起動は、最後の記録までで整理を閉じ、その後の空白を実作業へ加算しない。
- [x] 現在の仕事・今日・履歴・振り返りで整理時間を表示し、一時停止から分ける。

## やらないこと

計測方式の追加とタスク未割当開始。

## 設計メモ

contracts/coreに`task-management`停止理由を追加する。desktopは実窓の開閉を監視し、再起動復元と終了時の閉鎖を扱う。rendererは整理時間と停止を表示する。コマンド数は44のまま。

## 検証

- `pnpm run typecheck` / `lint` / `test` / `build` 成功。全130テスト、44コマンドを維持。
- `node scripts/e2e.mjs` と `node scripts/e2e-session-modes.mjs` 成功。後者は整理窓の開閉・既存停止・満了回帰・描画例外の12項目を検証。
- `pnpm run pack` 後の配布EXEでも両E2E成功。
- 実行中からの整理と、手動停止を維持する整理の実描画PNGを確認。
- 整理停止の開始処理を意図的に無効化すると2件が実作業加算・復旧停止の不一致で失敗し、復元後に管理時間の4件が成功した。
