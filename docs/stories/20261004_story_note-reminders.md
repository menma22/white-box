# 指定したノートを思い出す

## 目的

[ノート編集](20261004_story_notes-editor.md)で残した内容を、ピン留めと予定日時で今日の画面へ戻し、指定日時にはアプリの窓がなくてもOS通知で思い出せるようにする。

## 受け入れ基準

- [x] ノートに予定日時を設定・変更・解除できる。
- [x] 今日にピン留めと日時指定のノートを表示し、該当ノートへ移動できる。
- [x] 「確認した」で予定日時だけを解除し、本文とピン留めを保持する。
- [x] 期限に達した未通知のノートをメインプロセスで通知し、通知済みの印を保存して再起動後の重複を防ぐ。
- [x] 予定変更中の古い通知完了で新しい予定を消さず、アーカイブ中と未来の予定は通知しない。
- [x] アプリの窓と作業セッションがない状態でも通知し、アプリ終了時は監視と通知を止める。
- [x] ノート編集段階の日時項目がない保存データを読み込み、本文・関連先・ピン留めを保持する。
- [x] 実ElectronでUI・保存・再起動・最小画面幅とOS通知の接続を確認する。

## やらないこと

繰り返し通知、開始画面への表示、ノートの完全削除は含めない。

## 設計メモ

coreとcontractsへ予定日時と通知済みの印を加える。読み込みスキーマで旧ノートの日時をnullに補う。desktopのノート操作とメインプロセスの独立した通知監視を接続し、rendererの日時入力と今日のReminderPanelを追加する。

## 検証

- `pnpm run typecheck`・`pnpm run lint`・`pnpm run test`・`pnpm run build` を通過。単体テスト145件が成功。
- `node scripts/e2e.mjs` と `node scripts/e2e-notes.mjs` を通過。ノートE2Eは19項目が成功し、rendererエラーは0件。実Electronの日時保存・今日の表示・該当ノートへの移動・確認による日時解除・保存と再起動を確認。
- 日時入力・今日のリマインド・940×620のPNGを目視確認。本文230px、編集面455.4px、編集幅413.3px、横方向のはみ出し0px。
- `node scripts/verify-note-reminders.cjs` は14項目を通過。窓0・セッション0の実Electronと隔離した実StoreでOS通知を確認。通知済みの印は表示呼び出し前に保存し、実5秒タイマー2周とStore再読込後の監視再作成でも通知は合計1回だった。
- ネイティブ通知のshowイベント1回、failedイベント0件を観測。OSトーストの画素は未確認。
- 旧ノートのディスク読込で本文・関連先・ピン留めを保持して日時をnullに補う。未来・アーカイブ・既通知のノートと他の保存データは不変。監視停止後の予定到達でも更新なし。
- タイマー解放を一時的に除くと停止テストが失敗し、復元後は通知監視5件が成功。
