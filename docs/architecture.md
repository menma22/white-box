# 実装の構成

どこに何があり、なぜそう分けたか。仕様は [product-spec.md](product-spec.md)、判断の記録は [decisions.md](decisions.md)。

---

## 全体像

```
electron/     メインプロセス。セッションの真実・タイマー・ウィンドウ・ショートカット・保存
shared/       型と時間計算。メインとレンダラの両方から使う純関数（テスト対象）
src/          レンダラ（React）。表示と入力だけ
scripts/      アイコン生成・デモデータ・撮影台・通し確認・配布物の組み立て
tests/        shared/ の時間計算に対する単体テスト
docs/         この文書群
assets/       アイコン（PNG / ICO）。scripts/make-icon.mjs が生成する
```

## なぜメインプロセスがセッションを持つのか

**ウィンドウを全部閉じてもタイマーが動き続ける必要がある**（仕様 §16）。レンダラにタイマーを置くと、ウィンドウを閉じた瞬間に計測が止まる。

だからメインプロセスが唯一の真実を持ち、レンダラは表示と入力に徹する。

```
レンダラ  ──[ whitebox:cmd ]──▶  メインプロセス
   │                                  │  状態を変える
   │                                  │  ファイルへ保存
   ◀──[ whitebox:state ]──────────────┘  変わった状態を全ウィンドウへ配る
   ◀──[ whitebox:tick  ]──────────────┘  毎秒の軽い更新（経過・残り）だけ
```

- **状態の配布はミューテーションのときだけ。** 毎秒の更新で状態全体を送ると無駄が大きいので、経過時間だけを別の軽い経路（tick）で流す。
- **レンダラからメインへ触れるのは `window.whitebox` だけ。** `electron/preload.cjs` が公開している関数以外は届かない。

## ウィンドウ

1つのレンダラを URL の hash（`#main`, `#start`, `#hud`, `#expire`, `#review`, `#current`）で使い分ける。生成は `electron/windows.ts` に集約。

| kind | 役割 | 特徴 |
| --- | --- | --- |
| `main` | 今日 / ボード / 記録 / 設定 | 通常ウィンドウ |
| `start` | 何をやるか選んで開始 | 最前面・枠なし・キーボード完結 |
| `hud` | 実行中の小窓 | 最前面・× で閉じても計測は続く |
| `expire` | 予定時間に到達 | 最前面（全画面アプリの上にも出す） |
| `review` | 終了レビュー | 通常ウィンドウ |
| `current` | 現在の仕事 | 最前面 |

最前面は `setAlwaysOnTop(true, 'screen-saver')` で出す。通常の alwaysOnTop では全画面アプリの下に隠れる。

## 時間の計算

**実作業時間 = 経過時間 − 一時停止の重なり。** この計算は `shared/engine.ts` の純関数だけが行う。副作用を持たないので、そのまま単体テストで固定できる。

```
focusMs(session, now)      セッション全体の実作業時間
segmentFocusMs(...)        区間ごと（その区間に重なる停止だけを引く）
remainingMs(...)           残り。満了後はマイナスになり超過を表す
dayKey(ts, dayStartHour)   一日の境目を考慮した日付キー
```

区間（Task Segment）ごとの計算で「その区間に重なる停止だけを引く」ことが要点。セッション全体の停止をどの区間からも引くと、合計が合わなくなる。

## 状態遷移

`shared/session-ops.ts` が、開始・一時停止・再開・タスク切替・延長・満了・終了・進捗記録を扱う。すべて **新しい Session を返す純関数** で、終了済みのセッションは動かさない（記録を後から変えないため）。

## 保存

`electron/store.ts`。JSON 1ファイル + 日次バックアップ。

- 書き込みは**一時ファイルを作ってから置き換える**。途中で落ちても本体が壊れない
- `%APPDATA%\white-box\data\data.json`。`WHITEBOX_DATA_DIR` で差し替えられる（テストと動作確認で使う）
- `backups/` に日ごとのコピーを 30 日ぶん
- 読み込みに失敗したファイルは消さずに退避する

## 復旧

セッション中にアプリが落ちると、次の起動時にそのセッションが開いたまま残る。実行中は 15 秒ごとに「生きている時刻」を別ファイルへ書いているので、その時刻で止めてから人間に聞く。

- **その時刻で終了する** — PC が落ちていた時間は実作業に入らない
- **続きから再開する** — 短時間の再起動ならこちら

## レンダラの分け方

```
src/routes/    ウィンドウ1つ = ファイル1つ
src/views/     メインウィンドウの中身（今日 / ボード / 記録 / 設定 / Welcome / 部品）
src/ui/        画面をまたぐ部品（ボタン・リング・進捗バー・モーダルなど）
src/lib/       状態から表示用の値を導く関数
src/styles/    トークン → 部品 → 画面レイアウト の順で読む
src/store.ts   メインから配られた状態を持つだけ。計算はしない
src/bridge.ts  window.whitebox の薄い包み
```

`src/dev/fixture.ts` はブラウザで開いたときの見た目確認用の固定データ。**ここにコマンドの処理を書かない**（本体と二重実装になり、静かにずれる）。
