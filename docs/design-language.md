# 見た目の決まり

**「よく晴れた午後のカフェ」。** そこにいるだけで気分が上がる場所の空気を、作業道具に移す。

色を直接書かず、必ず `src/styles/tokens.css` のトークンを使う。散らすと空気感が壊れる。

---

## 色

| 役割 | 値 | 使いどころ |
| --- | --- | --- |
| 地 | `#f5f2ec` | ウィンドウの背景。クラフト紙のクリーム |
| 作業面 | `#fffefb` | 中身を読む面。紙の白 |
| 文字 | `#37312b` | 温かい黒。純黒は使わない |
| ハウスグリーン | `#1e3932` | 主要ボタン・ブランド・完了 |
| エプロングリーン | `#00704a` | 実行中・進捗・アクセント |
| キャラメル | `#b8813a` | 超過・注意・重要の印。**ここだけ** |
| 焙煎の赤茶 | `#b4553f` | 削除など戻せない操作 |

**差し色は緑一点。** 例外はキャラメル（超過と注意）と赤茶（危険）だけ。プロジェクトの色だけは色相を自由に選べるが、彩度と明度は固定して調和を保つ。

影は茶色寄り（`rgba(74, 56, 38, ...)`）。黒い影はクリーム地の上で灰色に濁る。

## 形

**構造は控えめに、操作するものは丸く。**

- 面・枠・カード → 角丸 6〜18px、影はほぼ無し、1px の枠で立たせる
- ボタン・チップ・タブ → ピル型（完全な丸み）

ホバーは浮かせず、背景の色で示す。持ち上がるのは「開始」まわりの主要な導線だけ。

## 書体

**Windows 標準のみ。ネットに取りに行かない**（起動が速く、オフラインで壊れない）。

| 用途 | 書体 |
| --- | --- |
| 見出し・ラベル・数字 | Segoe UI Variable Display |
| 感情の乗る見出し | Georgia（Welcome の挨拶、セクション名、セッションのひとこと） |
| 本文（日本語含む） | Yu Gothic UI |

- 数字は `tabular-nums`。秒が動いても桁がずれない
- Georgia は既定がオールドスタイル数字で、日本語文中の数字が小文字のように見えるため `lining-nums` を当てる
- 日本語の折り返しは `word-break: auto-phrase` で文節で切る

## 時間の見せ方

**時刻と長さを見間違えさせない。**

- 長さは `3h 25m` の形。`3:25` は時計と混同する
- 大きく見せる時間は単位だけ小さく落とす（`BigDuration`）
- 残り時間のカウントダウンだけは `20:00` の形でよい（時計ではなく減っていく量だと分かるため）

## 動き

意味のある瞬間にだけ動かす。

- 画面の切り替わり: 8px 下から浮き上がる（0.28s）
- 実行中の点: ゆっくり呼吸する（2.6s）
- 進捗バー: 幅の変化を 0.55s
- `prefers-reduced-motion` では全部止める

## アイコン

**上から覗いた開いた箱。** 四隅の斜めの筋が箱の角、内側の明るい面が中身、長さの違う3本の帯が積み上がった記録。一番下の短いキャラメルの帯が「まだ書き終えていない今日」。

名前（White Box）の由来と同じ意味を持たせている——中が読める箱。

画像ライブラリを使わず、PNG と ICO を直接組み立てて生成する（`pnpm icons` → `scripts/make-icon.mjs`）。16px でも「暗い枠・明るい面・色の帯」で読める形にしてある。

## 言葉

- **責めない。** 「3日サボっています」ではなく「これを重要に決めたのに、12日動いていない。今後どうする？」
- **逃がさない。** 現実の数字はそのまま出す。少ない日は少ないと見える
- **短く、具体的に。** ボタンは「終了する」「+15分 続ける」のように、押すと何が起きるかを書く
- **敬語にしない。** 自分の道具なので、自分に話しかける距離感で書く
